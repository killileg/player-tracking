# Intro
The goal of this project is to learn how to build a simple agentic workflow. 
We will call computer vision agent to track a player during a football game and produce a heatmap of its recorded positioning.

1. Obtain videos of games (available on Roboflow)
2. ID all players, allow to track ID we want
3. Generate heatmap of chosen ID
